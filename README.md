# Thief II VR

An unofficial VR port of Thief II: The Metal Age, played in your browser.
The current version includes the first mission, Running Interference.

## What you need

- Your own installed copy of Thief II: The Metal Age.
- A Windows PC to prepare the game files.
- A VR headset and a browser that supports WebXR. Use Quest Browser for
  standalone Quest, or a compatible PC browser with SteamVR for PC VR.

## How to play

1. Download **pack-thief2.ps1** from the game page.
2. Put it in your Thief II installation folder, alongside **Thief2.exe**.
3. Right-click the script and select **Run with PowerShell**. Wait for it
   to create **Thief2-VR-assets.zip** in the same folder, then press Enter
   to close the window.
4. Open the game page on the device you will play on and select
   **Choose game ZIP**. Choose the ZIP you just created.
5. Select **Play**, wait for the mission to load, then select **Enter VR**.

For standalone Quest, copy the ZIP from your PC to the headset before
step 4, then open the page in Quest Browser.

## Playing again

Your imported game files are saved in this browser on this device. On
later visits, select **Play** without importing again. If you clear the
site's browser data or switch devices or browsers, import the ZIP again.

Your game files stay on your device.

If you need to create a new ZIP, move or rename the old ZIP before running
the script again. If it reports missing files, check that you placed the
script in the folder containing your installed game.
